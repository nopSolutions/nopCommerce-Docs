# 入門指南

如果您是 nopCommerce 的初學者，請按照以下步驟設定並運行您的商店：

## 1. 配置您的商店

- [配置一般商店設定](xref:zh-Hant/getting-started/advanced-configuration/your-store-information)
- [配置付款方式](xref:zh-Hant/getting-started/configure-payments/payment-methods/index)
- [配置配送選項](xref:zh-Hant/getting-started/configure-shipping/index)
- 配置使用者清單：建立[不同群組](xref:zh-Hant/running-your-store/customer-management/customer-roles)的使用者，賦予他們[對網站區域的個別存取權限](xref:zh-Hant/running-your-store/customer-management/access-control-list)及優惠等等。

## 2. 建立商品目錄並新增商品

商品目錄是您的顧客經常接觸的部分。因此，讓顧客能輕鬆瀏覽並找到所需的商品至關重要。

### 建立類別與製造商

類別與製造商將用於您的商品目錄中進行商品篩選。了解如何處理這些設定，讓網站導覽變得更容易。

- [類別](xref:zh-Hant/running-your-store/catalog/categories)
- [製造商](xref:zh-Hant/running-your-store/catalog/manufacturers)

### 新增商品

您可以手動逐一新增商品，或從 XML 檔案匯入您的商品目錄。

- [商品](xref:zh-Hant/running-your-store/catalog/products/index)

### 定義商品子變體

如果您的商品具有多樣性，例如：您銷售不同顏色和尺寸的運動鞋該怎麼辦？在 nopCommerce 中，您可以設定規格屬性與商品屬性來管理這些情況。

- [組合商品 (子變體)](xref:zh-Hant/running-your-store/catalog/products/grouped-products-variants)

## 3. 提升商店的顧客體驗

現在您的商品目錄已填滿商品，請確保您的顧客在購買過程中能獲得所需的所有支援。

### 商品評價

個人的購買經驗非常重要。這能讓大眾對您這位賣家產生更多信任。在這裡學習如何為您的網路商店啟用商品評價並進行管理。

- [商品評價](xref:zh-Hant/running-your-store/catalog/products/product-reviews)

### LiveChat 即時客服支援

顧客通常需要即時提問。LiveChat 選項是協助他們的好方法。您可以在 nopCommerce 市集中找到聊天外掛。

- [了解更多關於 nopCommerce 外掛的資訊](xref:zh-Hant/getting-started/advanced-configuration/plugins-in-nopcommerce)

### 願望清單

願望清單是延後購買的一個好選擇。讓您的顧客將某些商品加入願望清單，以便稍後購買或與朋友分享。這也是您分析顧客行為的一個好方法。

- [購物車與願望清單](xref:zh-Hant/running-your-store/order-management/shopping-carts-and-wishlists)

## 4. 行銷與促銷工具

商店行銷對於贏得顧客忠誠度以及提升潛在顧客的知名度至關重要。nopCommerce 提供許多行銷選項：您可以提供特惠價格、根據購物行為推薦商品、透過電子郵件行銷活動推廣您的商店等等。

- [促銷工具](xref:zh-Hant/running-your-store/promotional-tools/index)

### 折扣與特惠價格

對商品套用特惠價格可以鼓勵您的顧客更快做出購買決定，及（或）購買更多商品。

- [折扣](xref:zh-Hant/running-your-store/promotional-tools/discounts)
- [階梯價格](xref:zh-Hant/running-your-store/promotional-tools/tier-prices)

### 忠誠度計畫

nopCommerce 中的紅利點數功能允許顧客透過特定行為（註冊、進行購買）賺取點數。

- [紅利點數](xref:zh-Hant/running-your-store/promotional-tools/reward-points)

### 交叉行銷

在 nopCommerce 中，您可以根據顧客的購物行為推薦他們可能感興趣的[額外商品](xref:zh-Hant/running-your-store/promotional-tools/cross-sells-and-related-products)。這也是您進行商品追加銷售 (up-sell) 的好機會。

### 電子郵件行銷活動

建立[電子郵件行銷活動](xref:zh-Hant/running-your-store/promotional-tools/email-campaigns)，以輕鬆快速地向您的目標客群發送特惠資訊、新聞、教育內容等。

## 5. 適用於各類型商店的 nopCommerce 特色功能

無論您是想嘗試一個小型專案，還是準備開始經營市集，您都可以信賴 nopCommerce。這裡有許多選項可滿足您的業務需求：

### 多商店 (Multi-store)

nopCommerce 讓您能透過單一 nopCommerce 安裝程式，使用同一個介面運行多個商店，並從單一面板管理所有後台作業。[從這裡了解](xref:zh-Hant/getting-started/advanced-configuration/multi-store)如何設定多個商店。

- [多商店](xref:zh-Hant/getting-started/advanced-configuration/multi-store)

### 多供應商 (Multi-vendor)

多供應商與直運 (Drop shipping) 工具讓您無需囤貨或配送訂單即可在線上銷售。觀看關於多供應商支援的[影片教學](https://www.youtube.com/watch?v=MH6r6tqfLF8&index=9&list=PLnL_aDfmRHwsbhj621A-RFb1KnzeFxYz4)。

- [供應商管理](xref:zh-Hant/running-your-store/vendor-management)
