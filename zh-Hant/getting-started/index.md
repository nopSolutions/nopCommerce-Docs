# 入門指南

如果您是 nopCommerce 的新手，請按照以下步驟設定並執行您的商店：

## 1. 設定您的商店

- [設定一般商店設定](xref:zh-Hant/getting-started/advanced-configuration/your-store-information)
- [設定付款方式](xref:zh-Hant/getting-started/configure-payments/payment-methods/index)
- [設定配送選項](xref:zh-Hant/getting-started/configure-shipping/index)
- 設定使用者列表：建立[不同的使用者群組](xref:zh-Hant/running-your-store/customer-management/customer-roles)，為其提供[網站區域與優惠的個別存取權限](xref:zh-Hant/running-your-store/customer-management/access-control-list)等。

## 2. 建立商品目錄並新增商品

商品目錄是您的顧客經常接觸的部分。因此，讓商品目錄易於瀏覽並能輕鬆找到所需商品至關重要。

### 建立類別與製造商

類別與製造商將用於商品目錄中的商品篩選。瞭解如何處理這些項目以使網站導覽更加容易。

- [類別](xref:zh-Hant/running-your-store/catalog/categories)
- [製造商](xref:zh-Hant/running-your-store/catalog/manufacturers)

### 新增商品

您可以手動逐一新增商品，或從 XML 檔案匯入您的商品目錄。

- [商品](xref:zh-Hant/running-your-store/catalog/products/index)

### 定義商品款式

如果您的商品有多種款式，例如：您販售不同顏色和尺寸的運動鞋？在 nopCommerce 中，您可以設定規格與商品屬性來管理這些內容。

- [組合商品 (款式)](xref:zh-Hant/running-your-store/catalog/products/grouped-products-variants)

## 3. 提升商店的顧客體驗

現在您的商品目錄已填滿商品，請確保您的顧客在購買過程中獲得所需的所有支援。

### 商品評論

個人購買經驗非常重要。這能讓大眾對您身為賣家更有信心。在此瞭解如何為您的線上商店啟用商品評論並進行管理。

- [商品評論](xref:zh-Hant/running-your-store/catalog/products/product-reviews)

### 即時對話 (LiveChat) 支援

顧客通常需要立即詢問問題。即時對話選項是協助他們的好方法。您可以在 nopCommerce 市集中找到對話外掛。

- [瞭解更多關於 nopCommerce 外掛的資訊](xref:zh-Hant/getting-started/advanced-configuration/plugins-in-nopcommerce)

### 願望清單

願望清單是延後購買的一個好選擇。讓您的顧客將商品加入願望清單以便日後購買或與朋友分享。這也是您分析顧客行為的一個好方法。

- [購物車與願望清單](xref:zh-Hant/running-your-store/order-management/shopping-carts-and-wishlists)

## 4. 行銷與促銷工具

商店行銷對於贏得顧客忠誠度以及提高潛在顧客的知名度至關重要。nopCommerce 提供許多行銷選項：您可以提供特價商品、根據購物行為推薦商品、透過電子郵件行銷活動推廣您的商店等等。

- [促銷工具](xref:zh-Hant/running-your-store/promotional-tools/index)

### 折扣與特價

對商品套用特價可以鼓勵您的顧客更早購買及（或）購買更多。

- [折扣](xref:zh-Hant/running-your-store/promotional-tools/discounts)
- [階層價格](xref:zh-Hant/running-your-store/promotional-tools/tier-prices)

### 忠誠度計畫

nopCommerce 中的紅利點數功能允許顧客透過特定行為（註冊、購買）賺取點數。

- [紅利點數](xref:zh-Hant/running-your-store/promotional-tools/reward-points)

### 交叉行銷

在 nopCommerce 中，您可以根據顧客的購物行為提供他們可能喜歡的[額外商品](xref:zh-Hant/running-your-store/promotional-tools/cross-sells-and-related-products)。這也是您進行商品追加銷售（Up-sell）的好機會。

### 電子郵件行銷活動

建立[電子郵件行銷活動](xref:zh-Hant/running-your-store/promotional-tools/email-campaigns)，以便輕鬆快速地向您的目標受眾傳遞特價優惠、新聞、教育內容等。

## 5. 適用於各類型商店的 nopCommerce 特殊功能

無論您是想嘗試小型專案還是要啟動大型市集平台，您都可以信賴 nopCommerce。這裡有許多選項可滿足您的業務需求：

### 多商店 (Multi-store)

nopCommerce 讓您能透過單一的 nopCommerce 安裝程式，在同一個介面中執行多個商店，並從單一面板管理所有後台管理作業。[在此瞭解](xref:zh-Hant/getting-started/advanced-configuration/multi-store)如何設定多個商店。

- [多商店](xref:zh-Hant/getting-started/advanced-configuration/multi-store)

### 多供應商 (Multi-vendor)

多供應商與直運 (Drop shipping) 工具讓您無需囤貨或親自配送訂單即可進行線上銷售。觀看關於多供應商支援的[教學影片](https://www.youtube.com/watch?v=MH6r6tqfLF8&index=9&list=PLnL_aDfmRHwsbhj621A-RFb1KnzeFxYz4)。

- [供應商管理](xref:zh-Hant/running-your-store/vendor-management)
