# 入門指南

如果您是 nopCommerce 的新手，請按照以下步驟設定並執行您的商店：

## 1. 設定您的商店

- [設定一般商店設定](xref:zh-Hant/getting-started/advanced-configuration/your-store-information)
- [設定付款方式](xref:zh-Hant/getting-started/configure-payments/payment-methods/index)
- [設定配送選項](xref:zh-Hant/getting-started/configure-shipping/index)
- 設定使用者清單：建立[不同的使用者群組](xref:zh-Hant/running-your-store/customer-management/customer-roles)，賦予他們[對網站區域的個別存取權限](xref:zh-Hant/running-your-store/customer-management/access-control-list)與優惠等等。

## 2. 建立商品目錄並新增商品

商品目錄是顧客最常接觸的部分。因此，確保目錄易於瀏覽且能輕鬆找到所需商品至關重要。

### 建立類別與製造商

類別與製造商將用於商品目錄中的商品篩選。瞭解如何處理它們，讓網站導覽更輕鬆。

- [類別](xref:zh-Hant/running-your-store/catalog/categories)
- [製造商](xref:zh-Hant/running-your-store/catalog/manufacturers)

### 新增商品

您可以手動逐一新增商品，或從 XML 檔案匯入商品目錄。

- [商品](xref:zh-Hant/running-your-store/catalog/products/index)

### 定義商品變體

如果您的商品有多種樣式，例如您販售不同顏色和尺寸的運動鞋？在 nopCommerce 中，您可以設定規格與商品屬性來管理。

- [組合商品（變體）](xref:zh-Hant/running-your-store/catalog/products/grouped-products-variants)

## 3. 提升商店的顧客體驗

既然商品目錄已填滿商品，請確保顧客在購買過程中獲得所需的所有支援。

### 商品評價

個人購買經驗很重要。這能讓顧客對身為賣家的您更有信心。在此瞭解如何為您的線上商店啟用並管理商品評價。

- [商品評價](xref:zh-Hant/running-your-store/catalog/products/product-reviews)

### 線上對話（LiveChat）支援

顧客通常需要即時提問。線上對話（LiveChat）選項是協助他們的好方法。在 nopCommerce 市集中可以找到聊天外掛。

- [瞭解更多關於 nopCommerce 外掛的資訊](xref:zh-Hant/getting-started/advanced-configuration/plugins-in-nopcommerce)

### 願望清單

願望清單是延後購買的好選擇。讓您的顧客將商品加入願望清單以便稍後購買或與朋友分享。這也是您分析顧客行為的好方法。

- [購物車與願望清單](xref:zh-Hant/running-your-store/order-management/shopping-carts-and-wishlists)

## 4. 行銷與促銷工具

對商店進行行銷對於贏得顧客忠誠度並提高潛在顧客的知名度至關重要。nopCommerce 提供許多行銷選項：您可以提供優惠價格、根據購物行為推薦商品、透過電子郵件活動推廣商店等等。

- [促銷工具](xref:zh-Hant/running-your-store/promotional-tools/index)

### 折扣與優惠價格

對商品套用優惠價格可以鼓勵顧客儘早購買或購買更多。

- [折扣](xref:zh-Hant/running-your-store/promotional-tools/discounts)
- [階梯價格](xref:zh-Hant/running-your-store/promotional-tools/tier-prices)

### 忠誠度計畫

nopCommerce 中的紅利點數功能允許顧客透過特定行為（註冊、購物）賺取點數。

- [紅利點數](xref:zh-Hant/running-your-store/promotional-tools/reward-points)

### 交叉行銷

在 nopCommerce 中，您可以根據顧客的購物行為向他們提供可能喜歡的[額外商品](xref:zh-Hant/running-your-store/promotional-tools/cross-sells-and-related-products)。這也是您進行追加銷售（Up-selling）的好機會。

### 電子郵件行銷活動

建立[電子郵件行銷活動](xref:zh-Hant/running-your-store/promotional-tools/email-campaigns)，以優惠方案、新聞、教育內容等資訊輕鬆快速地觸及您的目標受眾。

## 5. 適用於各類商店的 nopCommerce 特色功能

無論您是想嘗試小型專案還是要啟動大型市集平台，都可以信賴 nopCommerce。有許多選項可以滿足您的業務需求：

### 多商店

nopCommerce 讓您能透過單一介面，從單次 nopCommerce 安裝中運行多個商店，並從單一後台管理所有操作。[點擊此處](xref:zh-Hant/getting-started/advanced-configuration/multi-store)瞭解如何設定多個商店。

- [多商店](xref:zh-Hant/getting-started/advanced-configuration/multi-store)

### 多供應商

多供應商與直運（Drop shipping）工具讓您無需庫存或自行配送即可在線銷售。觀看關於多供應商支援的[教學影片](https://www.youtube.com/watch?v=MH6r6tqfLF8&index=9&list=PLnL_aDfmRHwsbhj621A-RFb1KnzeFxYz4)。

- [供應商管理](xref:zh-Hant/running-your-store/vendor-management)
