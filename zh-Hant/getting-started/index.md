# 入門指南

如果您是 nopCommerce 的新手，請按照以下步驟來設定並運行您的商店：

## 1. 設定您的商店

- [設定一般商店設定](xref:en/getting-started/advanced-configuration/your-store-information)
- [設定付款方式](xref:en/getting-started/configure-payments/payment-methods/index)
- [設定配送選項](xref:en/getting-started/configure-shipping/index)
- 設定使用者列表：建立[不同的使用者群組](xref:en/running-your-store/customer-management/customer-roles)，為他們提供[網站區域和優惠的個別存取權限](xref:en/running-your-store/customer-management/access-control-list)等等。

## 2. 建立商品目錄並新增商品

商品目錄是您的顧客經常接觸的部分。因此，讓顧客能輕鬆瀏覽並找到所需的商品至關重要。

### 建立類別與製造商

類別與製造商將用於您的商品目錄中以進行商品篩選。了解如何處理它們以讓網站導覽更輕鬆。

- [類別](xref:en/running-your-store/catalog/categories)
- [製造商](xref:en/running-your-store/catalog/manufacturers)

### 新增商品

您可以手動逐一新增商品，或從 xml 檔案匯入您的商品目錄。

- [商品](xref:en/running-your-store/catalog/products/index)

### 定義商品多樣性

如果您的商品有多種變化，例如：您銷售各種顏色和尺寸的運動鞋？在 nopCommerce 中，您可以透過設定規格與商品屬性來管理這些。

- [組合商品（變體）](xref:en/running-your-store/catalog/products/grouped-products-variants)

## 3. 提升商店的顧客體驗

既然您的商品目錄已經填滿了商品，請確保您的顧客在購買過程中獲得所需的所有支援。

### 商品評論

個人的購買經驗非常重要。它會讓顧客更信任您這位賣家。在此了解如何為您的線上商店啟用商品評論並進行管理。

- [商品評論](xref:en/running-your-store/catalog/products/product-reviews)

### 即時通訊 (LiveChat) 支援

顧客經常需要立即詢問問題。即時通訊 (LiveChat) 選項是幫助他們的好方法。您可以在 nopCommerce 市集中找到聊天外掛。

- [了解更多關於 nopCommerce 外掛的資訊](xref:en/getting-started/advanced-configuration/plugins-in-nopcommerce)

### 願望清單

願望清單是延後購買的一個好選擇。讓您的顧客將一些商品加入願望清單以供日後購買或與朋友分享。這也是您分析顧客行為的一個好方法。

- [購物車與願望清單](xref:en/running-your-store/order-management/shopping-carts-and-wishlists)

## 4. 行銷與促銷工具

行銷您的商店對於獲得顧客忠誠度並提高潛在顧客的知名度至關重要。nopCommerce 中有許多行銷選項：您可以提供特惠價格、根據購物行為建議商品、透過電子郵件活動宣傳您的商店等等。

- [促銷工具](xref:en/running-your-store/promotional-tools/index)

### 折扣與特惠價格

對商品套用特惠價格可以鼓勵您的顧客儘早購買且（或）購買更多。

- [折扣](xref:en/running-your-store/promotional-tools/discounts)
- [階層價格](xref:en/running-your-store/promotional-tools/tier-prices)

### 忠誠度計畫

nopCommerce 中的紅利點數功能允許顧客透過特定行為（註冊、進行購買）賺取點數。

- [紅利點數](xref:en/running-your-store/promotional-tools/reward-points)

### 交叉行銷

在 nopCommerce 中，您可以根據顧客的購物行為提供他們可能感興趣的[額外商品](xref:en/running-your-store/promotional-tools/cross-sells-and-related-products)。這也是您進行追加銷售 (up-sell) 商品的好機會。

### 電子郵件活動

建立[電子郵件活動](xref:en/running-your-store/promotional-tools/email-campaigns)，以便輕鬆快速地向您的目標受眾發送特惠資訊、新聞、教育內容等。

## 5. 適用於各類商店的 nopCommerce 特殊功能

無論您是想嘗試一個小型專案還是要啟動一個市集平台，您都可以信賴 nopCommerce。有許多選項可以滿足您的業務需求：

### 多商店

nopCommerce 使您能夠從單一的 nopCommerce 安裝中透過一個介面運行多個商店，並從單一面板管理所有後台作業。[在此了解](xref:en/getting-started/advanced-configuration/multi-store)如何設定多個商店。

- [多商店](xref:en/getting-started/advanced-configuration/multi-store)

### 多供應商

多供應商與直運 (drop shipping) 工具使您無需庫存或自行配送訂單即可在線上銷售。觀看關於多供應商支援的[影片教學](https://www.youtube.com/watch?v=MH6r6tqfLF8&index=9&list=PLnL_aDfmRHwsbhj621A-RFb1KnzeFxYz4)。

- [供應商管理](xref:en/running-your-store/vendor-management)
