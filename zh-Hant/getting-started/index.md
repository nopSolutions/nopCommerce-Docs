# 快速入門

如果您是 nopCommerce 的新手，請按照以下步驟設定並執行您的商店：

## 1. 設定您的商店

- [設定一般商店設定](xref:en/getting-started/advanced-configuration/your-store-information)
- [設定付款方式](xref:en/getting-started/configure-payments/payment-methods/index)
- [設定配送選項](xref:en/getting-started/configure-shipping/index)
- 設定使用者列表：建立[不同的使用者群組](xref:en/running-your-store/customer-management/customer-roles)，給予他們[網站區域的個別存取權限](xref:en/running-your-store/customer-management/access-control-list)與優惠等等。

## 2. 建立商品目錄並新增商品

商品目錄是顧客經常接觸的部分。因此，讓商品目錄易於瀏覽並能輕鬆找到所需商品至關重要。

### 建立類別與製造商

類別與製造商將用於商品目錄中的商品過濾。了解如何處理它們以使網站導覽更加容易。

- [類別](xref:en/running-your-store/catalog/categories)
- [製造商](xref:en/running-your-store/catalog/manufacturers)

### 新增商品

您可以手動逐一新增商品，或從 XML 檔案匯入您的商品目錄。

- [商品](xref:en/running-your-store/catalog/products/index)

### 定義商品變體

如果您的商品有多種變體，例如您銷售不同顏色和尺寸的運動鞋該怎麼辦？在 nopCommerce 中，您可以設定規格與商品屬性來管理。

- [組合商品（變體）](xref:en/running-your-store/catalog/products/grouped-products-variants)

## 3. 提升商店的顧客體驗

現在您的商品目錄已填滿商品，請確保您的顧客在購買過程中獲得所需的所有支援。

### 商品評論

個人的購買經驗非常重要。這會讓大眾對您這位賣家產生更多信任。在此了解如何為您的線上商店提供並管理商品評論。

- [商品評論](xref:en/running-your-store/catalog/products/product-reviews)

### LiveChat 支援

您的顧客通常需要即時提問。LiveChat 選項是協助他們的好方法。您可以在 nopCommerce 市集中找到聊天外掛。

- [深入了解 nopCommerce 中的外掛](xref:en/getting-started/advanced-configuration/plugins-in-nopcommerce)

### 願望清單

願望清單是延後購買的好選擇。讓您的顧客將某些商品加入願望清單以便日後購買或與朋友分享。這也是您分析顧客行為的好工具。

- [購物車與願望清單](xref:en/running-your-store/order-management/shopping-carts-and-wishlists)

## 4. 行銷與促銷工具

行銷您的商店對於獲得顧客忠誠度並提高潛在顧客的意識至關重要。nopCommerce 中有許多行銷選項：您可以提供特惠價、根據購物行為建議商品、透過電子郵件行銷活動推廣您的商店等等。

- [促銷工具](xref:en/running-your-store/promotional-tools/index)

### 折扣與特惠價

對商品套用特惠價可以鼓勵您的顧客儘早購買和（或）購買更多。

- [折扣](xref:en/running-your-store/promotional-tools/discounts)
- [階梯價格](xref:en/running-your-store/promotional-tools/tier-prices)

### 忠誠度計畫

nopCommerce 中的紅利點數功能允許顧客透過特定操作（註冊、進行購買）賺取點數。

- [紅利點數](xref:en/running-your-store/promotional-tools/reward-points)

### 交叉行銷

在 nopCommerce 中，您可以根據顧客的購物行為向他們提供可能喜歡的[額外商品](xref:en/running-your-store/promotional-tools/cross-sells-and-related-products)。這也是您進行商品向上銷售（Up-selling）的好機會。

### 電子郵件行銷活動

建立[電子郵件行銷活動](xref:en/running-your-store/promotional-tools/email-campaigns)，以特惠活動、新聞、教育內容等輕鬆快速地觸及您的目標受眾。

## 5. 適用於各類商店的 nopCommerce 特色功能

無論您是想嘗試一個小型專案還是要啟動一個市集平台，您都可以信賴 nopCommerce。有許多選項可以滿足您的業務需求：

### 多商店

nopCommerce 讓您能使用單一 nopCommerce 安裝實例的介面執行多個商店，並從單一面板管理所有後台作業。[在此了解](xref:en/getting-started/advanced-configuration/multi-store)如何設定多個商店。

- [多商店](xref:en/getting-started/advanced-configuration/multi-store)

### 多供應商

多供應商與直運（Drop shipping）工具讓您無需庫存或親自配送訂單即可進行線上銷售。觀看關於多供應商支援的[教學影片](https://www.youtube.com/watch?v=MH6r6tqfLF8&index=9&list=PLnL_aDfmRHwsbhj621A-RFb1KnzeFxYz4)。

- [供應商管理](xref:en/running-your-store/vendor-management)
