# 使用入門

如果您是 nopCommerce 的新手，請按照以下步驟來設定並執行您的商店：

## 1. 設定您的商店

- [設定一般商店設定](xref:zh-Hant/getting-started/advanced-configuration/your-store-information)
- [設定付款方式](xref:zh-Hant/getting-started/configure-payments/payment-methods/index)
- [設定配送選項](xref:zh-Hant/getting-started/configure-shipping/index)
- 設定使用者清單：建立[不同的使用者群組](xref:zh-Hant/running-your-store/customer-management/customer-roles)，為他們提供[網站區域的個別存取權限](xref:zh-Hant/running-your-store/customer-management/access-control-list)與優惠等等。

## 2. 建立商品目錄並新增商品

商品目錄是您的顧客經常接觸的部分。因此，讓商品目錄易於瀏覽並能輕鬆找到所需商品至關重要。

### 建立分類與製造商

分類與製造商將用於商品目錄中的商品篩選。了解如何處理它們以使網站導覽更加容易。

- [分類](xref:zh-Hant/running-your-store/catalog/categories)
- [製造商](xref:zh-Hant/running-your-store/catalog/manufacturers)

### 新增商品

您可以逐一手動新增商品，或從 xml 檔案匯入您的商品目錄。

- [商品](xref:zh-Hant/running-your-store/catalog/products/index)

### 定義商品款式

如果您的商品具有多種款式，例如：您銷售各種顏色和尺寸的運動鞋該怎麼辦？在 nopCommerce 中，您可以設定規格與商品屬性來管理此類需求。

- [分組商品（款式）](xref:zh-Hant/running-your-store/catalog/products/grouped-products-variants)

## 3. 提升商店的顧客體驗

現在您的商品目錄已填滿了商品，請確保您的顧客在購買過程中獲得所需的所有支援。

### 商品評價

個人的購買經驗非常重要。這會讓顧客對身為賣家的您產生更多信任。在此了解如何讓您的線上商店啟用商品評價功能並進行管理。

- [商品評價](xref:zh-Hant/running-your-store/catalog/products/product-reviews)

### LiveChat 客服支援

您的顧客通常需要即時提問。LiveChat 選項是幫助他們的絕佳方式。您可以在 nopCommerce 市集中找到聊天外掛。

- [了解更多關於 nopCommerce 外掛的資訊](xref:zh-Hant/getting-started/advanced-configuration/plugins-in-nopcommerce)

### 願望清單

願望清單是延遲購買的好選擇。讓您的顧客將某些商品加入願望清單，以便稍後購買或分享給朋友。這也是您分析顧客行為的好方法。

- [購物車與願望清單](xref:zh-Hant/running-your-store/order-management/shopping-carts-and-wishlists)

## 4. 行銷與促銷工具

行銷您的商店對於獲得顧客忠誠度並提高潛在顧客的意識至關重要。nopCommerce 中有許多行銷選項：您可以提供特惠價格、根據購物行為推薦商品、透過電子郵件行銷活動推廣您的商店等等。

- [促銷工具](xref:zh-Hant/running-your-store/promotional-tools/index)

### 折扣與特惠價格

對商品應用特惠價格可以鼓勵您的顧客儘早購買和（或）購買更多。

- [折扣](xref:zh-Hant/running-your-store/promotional-tools/discounts)
- [階梯價格](xref:zh-Hant/running-your-store/promotional-tools/tier-prices)

### 忠誠度計畫

nopCommerce 中的紅利點數功能允許顧客透過特定行為（註冊、進行購買）賺取點數。

- [紅利點數](xref:zh-Hant/running-your-store/promotional-tools/reward-points)

### 交叉行銷

在 nopCommerce 中，您可以根據顧客的購物行為向他們提供可能喜歡的[額外商品](xref:zh-Hant/running-your-store/promotional-tools/cross-sells-and-related-products)。這也是您向上銷售 (up-sell) 某些商品的絕佳機會。

### 電子郵件行銷活動

建立[電子郵件行銷活動](xref:zh-Hant/running-your-store/promotional-tools/email-campaigns)，以便輕鬆快速地向您的目標受眾發送特惠訊息、新聞、教育內容等。

## 5. 適用於各類商店的 nopCommerce 特殊功能

無論您是想嘗試一個小型專案，還是要開始一個市集平台，您都可以信賴 nopCommerce。有許多選項可以滿足您的業務需求：

### 多商店 (Multi-store)

nopCommerce 使您能夠從單一 nopCommerce 安裝程式中使用一個介面執行多個商店，並從單一面板管理所有後台管理操作。[在此了解](xref:zh-Hant/getting-started/advanced-configuration/multi-store)如何設定多個商店。

- [多商店](xref:zh-Hant/getting-started/advanced-configuration/multi-store)

### 多供應商 (Multi-vendor)

多供應商與直運 (Drop shipping) 工具使您無需存放庫存或配送訂單即可進行線上銷售。觀看關於多供應商支援的[教學影片](https://www.youtube.com/watch?v=MH6r6tqfLF8&index=9&list=PLnL_aDfmRHwsbhj621A-RFb1KnzeFxYz4)。

- [供應商管理](xref:zh-Hant/running-your-store/vendor-management)
