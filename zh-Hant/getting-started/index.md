# 入門指南

如果您是 nopCommerce 的新手，請依照以下步驟設定並執行您的商店：

## 1. 設定您的商店

- [設定商店通用設定](xref:zh-Hant/getting-started/advanced-configuration/your-store-information)
- [設定付款方式](xref:zh-Hant/getting-started/configure-payments/payment-methods/index)
- [設定配送選項](xref:zh-Hant/getting-started/configure-shipping/index)
- 設定使用者列表：建立[不同的顧客角色](xref:zh-Hant/running-your-store/customer-management/customer-roles)，給予他們[存取網站特定區域](xref:zh-Hant/running-your-store/customer-management/access-control-list)或優惠的權限，以及更多功能。

## 2. 建立商品目錄並新增商品

商品目錄是顧客持續互動的核心，因此讓顧客能輕鬆瀏覽並找到所需的商品至關重要。

### 建立分類與製造商

分類與製造商將用於您的商品目錄，以進行商品篩選。了解如何管理這些項目，讓網站導覽更為簡便。

- [分類](xref:zh-Hant/running-your-store/catalog/categories)
- [製造商](xref:zh-Hant/running-your-store/catalog/manufacturers)

### 新增商品

您可以手動逐一新增商品，或從 XML 檔案匯入您的商品目錄。

- [商品](xref:zh-Hant/running-your-store/catalog/products/index)

### 定義商品變體

如果您的商品具有變體（例如：銷售多種顏色與尺寸的運動鞋）該怎麼辦？在 nopCommerce 中，您可以設定規格與商品屬性來管理這些需求。

- [組合商品（變體）](xref:zh-Hant/running-your-store/catalog/products/grouped-products-variants)

## 3. 改善商店的顧客體驗

現在您的商品目錄已上架完成，請確保顧客在購物旅程中能獲得所需的一切支援。

### 商品評論

個人化的購買體驗非常重要，這能增進人們對您作為賣家的信任。在此了解如何為您的線上商店啟用商品評論功能並進行管理。

- [商品評論](xref:zh-Hant/running-your-store/catalog/products/product-reviews)

### 即時通訊支援

顧客經常需要即時提問，LiveChat（即時通訊）選項是協助顧客的好方法。您可以在 nopCommerce 市集中找到通訊外掛。

- [了解更多關於 nopCommerce 的外掛](xref:zh-Hant/getting-started/advanced-configuration/plugins-in-nopcommerce)

### 願望清單

願望清單是延後購買的好選擇。讓顧客將商品加入願望清單以便稍後購買或分享給朋友。這同時也是您分析顧客行為的好方式。

- [購物車與願望清單](xref:zh-Hant/running-your-store/order-management/shopping-carts-and-wishlists)

## 4. 行銷與促銷工具

行銷您的商店對於贏得顧客忠誠度與提升潛在顧客的品牌認知至關重要。nopCommerce 提供許多行銷選項：您可以提供特價、根據購物行為推薦商品、透過電子郵件活動進行推廣等等。

- [促銷工具](xref:zh-Hant/running-your-store/promotional-tools/index)

### 折扣與特別價格

為商品套用特別價格，能鼓勵顧客更快完成購買（或）購買更多商品。

- [折扣](xref:zh-Hant/running-your-store/promotional-tools/discounts)
- [階梯價格](xref:zh-Hant/running-your-store/promotional-tools/tier-prices)

### 忠誠度計畫

nopCommerce 的紅利點數功能允許顧客透過特定操作（如：註冊、購物）來賺取點數。

- [紅利點數](xref:zh-Hant/running-your-store/promotional-tools/reward-points)

### 交叉行銷

在 nopCommerce 中，您可以根據顧客的購物行為，推薦他們可能感興趣的[額外商品](xref:zh-Hant/running-your-store/promotional-tools/cross-sells-and-related-products)。這也是您進行向上銷售的好機會。

### 電子郵件行銷活動

建立[電子郵件行銷活動](xref:zh-Hant/running-your-store/promotional-tools/email-campaigns)，輕鬆且快速地將特別優惠、最新消息、教育內容等資訊傳遞給您的目標受眾。

## 5. nopCommerce 為各類商店提供的特殊功能

無論您是想嘗試小型專案，還是準備啟動一個商城，nopCommerce 都能成為您的後盾。我們提供多種選項來滿足您的業務需求：

### 多商店

nopCommerce 讓您能透過單一安裝並在同一個介面下，執行多個商店，並從單一後台管理所有營運操作。請[由此了解](xref:zh-Hant/getting-started/advanced-configuration/multi-store)如何設定多個商店。

- [多商店](xref:zh-Hant/getting-started/advanced-configuration/multi-store)

### 多供應商

多供應商與直運工具讓您無需存放庫存或自行配送訂單即可在線上銷售。請觀看關於多供應商支援的[教學影片](https://www.youtube.com/watch?v=MH6r6tqfLF8&index=9&list=PLnL_aDfmRHwsbhj621A-RFb1KnzeFxYz4)。

- [供應商管理](xref:zh-Hant/running-your-store/vendor-management)
