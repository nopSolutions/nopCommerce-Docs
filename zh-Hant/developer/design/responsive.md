# 回應式設計

**了解回應式設計。** 回應式網頁設計（Responsive Web Design）簡而言之，就是一種網站設計方式，它能根據不同的螢幕尺寸改變版面配置，使內容在桌上型電腦、智慧型手機、平板電腦以及其他行動裝置上都能適當呈現。在這個定義中，有一個關鍵字：「適當」——在此語境下，「適當」意味著一致性。在進行回應式設計時，網頁開發人員必須確保網站的使用者體驗在所有裝置上都能保持一致，無論其螢幕尺寸為何。（來源：[nopCommerce 部落格](https://www.nopcommerce.com/why-a-responsive-design-should-be-a-priority-for-your-business-website)）

* 行動裝置的數量正以極快的速度增加，由於螢幕尺寸與解析度各異，網頁開發人員採用回應式設計方法，以確保網站的使用者體驗在各個平台上保持相同或相似。

* 是的，nopCommerce 的預設版面配置與佈景主題確實支援回應式設計，並針對所有螢幕尺寸進行了最佳化，這種設計方式是透過 CSS 中的 media-queries（媒體查詢）來實現的。這讓您的電子商務商店版面能根據螢幕大小自動調整顯示區域，進而呈現網站內容。

**檢視回應式設計。** 只需調整瀏覽器視窗的大小，並持續縮小視窗寬度。隨著瀏覽器視窗尺寸變小，您會看到 nopCommerce 網站會隨之自動調整內容。
