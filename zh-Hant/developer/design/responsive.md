# 回應式設計

**了解回應式設計。** 回應式網頁設計（Responsive Web Design）簡而言之，就是一種根據不同螢幕尺寸調整佈局的網站設計，旨在將內容妥善地呈現在桌上型電腦、智慧型手機、平板電腦及其他行動裝置上。此定義中，「妥善」（properly）是一個關鍵字，在此語境下，「妥善」代表的是「一致性」。在進行回應式設計時，網站開發人員必須確保網站的使用者體驗在所有裝置上都能保持一致，無論螢幕尺寸為何。（來源：[nopCommerce 部落格](https://www.nopcommerce.com/why-a-responsive-design-should-be-a-priority-for-your-business-website)）

* 行動裝置的數量正以極快的速度增長，由於螢幕尺寸與解析度各異，網站開發人員採用回應式設計方法，以確保網站的使用者體驗在各個平台上保持相同或相似。

* 是的，nopCommerce 的預設佈局/佈景主題支援針對所有螢幕尺寸進行優化過的回應式設計，這種方法是透過 CSS 中的媒體查詢（media-queries）來實現的。這讓您的電子商務商店佈局能夠根據螢幕大小自動調整顯示區域，進而呈現網站內容。

**檢視回應式設計。** 只需重新調整您的瀏覽器視窗大小並將其縮小。隨著瀏覽器視窗變小，您會看到 nopCommerce 網站會隨之調整內容。
