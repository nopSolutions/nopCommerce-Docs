# 提示與技巧

1. 網頁開發/設計中的主要問題之一，在於不同的瀏覽器對各種 CSS 屬性使用不同的預設值。在自訂或建立您的佈景主題時，請務必確保您的樣式與所有瀏覽器相容。請在 Edge、Firefox、Opera、Safari 和 Chrome 等主流瀏覽器中測試您的網站。
1. 在處理 CSS 樣式表時，如果您在網站上看不到任何變更，請不要驚慌。嘗試刪除瀏覽器的歷史記錄和 Cookie，然後重新整理頁面再試一次。
1. 請務必了解 id 和 class 之間的區別。您可以將 class 套用到多個元素，而 id 僅指向一個元素。
1. CSS 樣式表不允許您以數字或其他非字母字元作為 id 和 class 名稱的開頭。
1. 不要將自己侷限於 span 和 div 標籤。CSS 還提供了許多其他更好的功能來設定網頁樣式。

> [!TIP]
> 請善用 Mozilla 提供的 **Firefox Developer Tools** 外掛。這是一個非常有用的工具，可讓您在任何網頁上即時編輯、偵錯並監控 CSS、HTML 和 JavaScript。您可以在此處了解更多資訊：[Firefox Developer Tools。](https://developer.mozilla.org/en-US/docs/Tools)
>
> 或者，您也可以使用屬於 Chrome 瀏覽器一部分的 **Chrome DevTools 工具**。您可以在此處了解更多資訊：[Chrome DevTools。](https://developers.google.com/web/tools/chrome-devtools)
