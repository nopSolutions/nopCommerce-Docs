# 貢獻

我們非常歡迎您為 nopCommerce 的成功做出貢獻，無論是協助專案開發、參與論壇討論，還是單純協助宣傳！如果您擁有網站，歡迎撰寫關於我們的文章或放置超連結！我們致力於培育 nopCommerce 社群的成長！

nopCommerce 擁有一個年輕且不斷成長的貢獻者社群。這是一個非常活躍且充滿熱情的社群，致力於開發強大的 .NET Core 開源電子商務應用程式。nopCommerce 在上個月的下載量已超過 30,000 次，相當受歡迎。歡迎加入我們的社群，看看您能從中學到什麼，又能分享些什麼！
